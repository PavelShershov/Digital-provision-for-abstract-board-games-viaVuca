# viaVUCA

**viaVUCA** — веб-платформа для изучения, визуализации и тестирования по тактическим настольным играм.

Проект включает тренировочный режим, тестирование, 3D/AR-просмотр игровых партий и панель организатора для создания турнирных ссылок, фиксации ответов участников и выгрузки результатов.

## Основные возможности

* выбор и запуск тренажёров по отдельным играм;
* генерация задач разных типов;
* прохождение тестов участниками по турнирной ссылке;
* сохранение ответов и результатов прохождения;
* панель организатора турниров;
* просмотр созданных турнирных ссылок;
* выгрузка отчёта с результатами в формате Excel;
* 3D-плеер партий;
* AR-раздел для просмотра игровых материалов;
* адаптивный интерфейс для desktop, tablet и mobile.

## Технологический стек

### Frontend

* HTML5
* CSS3
* JavaScript
* Canvas API
* Web Components / DOM API
* 3D/AR-визуализация на клиентской стороне

### Backend

* PHP
* MySQL
* Beget hosting

### Хранение данных

Данные организаторов, турниров, участников, тестов, сессий прохождения и результатов сохраняются в базе данных MySQL на сервере Beget.

## Архитектура проекта

Проект состоит из двух основных частей:

1. **Клиентская часть**
   Статические HTML/CSS/JS-файлы, отвечающие за интерфейс, игровые тренажёры, тестирование, 3D/AR-просмотр и панель организатора.

2. **Серверная часть**
   PHP-обработчики на Beget, которые обеспечивают авторизацию организаторов, создание турниров, хранение конфигураций тестов, фиксацию ответов участников и экспорт отчётов.

## Игровая логика

Игровые задачи размещаются в папке `games/`.

Каждая игра содержит:

* `config.json` — конфигурация игры;
* изображения поля и фигур;
* координаты игровых клеток;
* генераторы задач;
* названия типов задач;
* дополнительные функции отрисовки.

Текущая система генерации задач использует глобальную регистрацию:

```javascript
window.taskGenerators = window.taskGenerators || {};
window.taskTitles = window.taskTitles || {};
window.originalCenters = originalCenters;
```

Это обеспечивает совместимость между игровыми файлами, тренировочным режимом и тестовым режимом.

В дальнейшем игровые скрипты могут быть разделены на модули:

```text
games/example/
├── config.json
├── board.js
├── rules.js
├── index.js
├── tasks/
│   ├── task-1.js
│   ├── task-2.js
│   └── index.js
└── assets/
```

## Серверная часть

Рабочая серверная часть размещается на хостинге Beget.

В репозитории может храниться демонстрационная структура backend-кода:

```text
backend/
├── api/
│   ├── api.php
│   ├── auth.php
│   ├── tournaments.php
│   ├── tests.php
│   ├── students.php
│   ├── results.php
│   └── export_results_xlsx_vendor.php
│
├── config/
│   └── config.example.php
│
└── database/
    ├── schema.sql
    └── seed.example.sql
```

Реальные параметры подключения к базе данных, пароли, токены и персональные данные не публикуются в репозитории.

## Безопасность

В публичный репозиторий не должны попадать:

* реальные логины и пароли MySQL;
* рабочий файл `config.php`;
* токены и приватные ключи;
* реальные данные участников;
* реальные результаты тестирования;
* дампы базы данных с персональными данными.

Для примера конфигурации используется файл:

```text
backend/config/config.example.php
```

Рабочий файл конфигурации создаётся отдельно на сервере Beget.

## Запуск проекта

### Локальный запуск frontend

Проект можно открыть как статический сайт через локальный сервер.

Например:

```bash
python -m http.server 8000
```

После запуска открыть в браузере:

```text
http://localhost:8000/welcome.html
```

### Запуск на Beget

Для размещения на Beget файлы frontend загружаются в корневую директорию сайта.

Для запуска `welcome.html` как стартовой страницы используется `.htaccess`:

```apache
DirectoryIndex welcome.html index.html
```

Серверная часть размещается в директории API на Beget и работает с MySQL.

## Экспорт результатов

Результаты тестирования могут быть выгружены организатором в Excel-файл через серверный PHP-обработчик.

Экспорт включает:

* список участников;
* ответы участников;
* количество правильных ответов;
* итоговый процент;
* баллы;
* максимальное количество баллов.
